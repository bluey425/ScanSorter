# ScanSorter

스캐너가 폴더에 쌓아놓은 PDF·이미지 파일을 **Gemini가 직접 읽고**, 내용에 맞는 파일명을 지어주고,
분류 폴더를 만들어 정리해주는 웹 앱입니다.

- 서버가 없습니다. **정적 HTML/CSS/JS 뿐**이라 주소만 알면 각자 PC의 브라우저에서 각자 동작합니다.
- 파일은 브라우저 → Google Gemini API로 **직접** 전송됩니다. 중간 서버를 거치지 않습니다.
- API 키는 사용자의 브라우저(localStorage)에만 저장됩니다.
- 스캔 문서가 이미지로만 되어 있어도 Gemini가 화면을 보고 읽으므로 별도 OCR이 필요 없습니다.

---

## 동작 환경

| 항목 | 요구사항 |
|---|---|
| 브라우저 | **Chrome 또는 Edge 데스크톱 86+** (File System Access API 필요) |
| 미지원 | Firefox, Safari, 모든 모바일 브라우저 |
| 접속 | `https://` 또는 `http://localhost` (보안 컨텍스트 필요) |
| API | Google AI Studio에서 발급한 Gemini API 키 (무료 플랜 가능) |

`file://`로 직접 열면 폴더 권한과 설정 저장이 동작하지 않습니다. 아래처럼 로컬 서버로 여세요.

---

## 실행

### 1) 로컬에서 바로 써보기

```bash
node serve.js        # http://localhost:8080  (의존성 없음)
```

또는 익숙한 도구가 있다면 `npx serve .` , `python -m http.server 8080` 도 됩니다.

브라우저에서 `http://localhost:8080` 접속.

### 2) 인터넷에 올려서 여러 사람이 쓰기

정적 파일만 있으므로 아무 정적 호스팅에나 올리면 됩니다.

**GitHub Pages**

```bash
git init && git add . && git commit -m "ScanSorter"
git branch -M main
git remote add origin https://github.com/<사용자명>/scansorter.git
git push -u origin main
```

저장소 → Settings → Pages → Source를 `main` / `/ (root)`로 지정하면
`https://<사용자명>.github.io/scansorter/` 주소가 생깁니다.

**Netlify / Vercel / Cloudflare Pages**: 이 폴더를 드래그 앤 드롭. 빌드 명령·출력 폴더 설정 없음.

## 사용법

1. **API 키 발급** — [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 발급 후 붙여넣고 `연결 확인`.
2. **폴더 선택** — 스캐너가 파일을 떨구는 폴더를 고르고 권한을 허용합니다.
   (선택한 폴더의 최상위 파일만 읽습니다. 하위 폴더는 건드리지 않습니다.)
3. **AI 분석 시작** — 파일마다 날짜·발행처·제목·분류를 뽑아 새 이름을 제안합니다.
4. **표에서 확인·수정** — 마음에 안 드는 이름이나 분류는 직접 고칠 수 있습니다.
   체크를 풀면 그 파일은 건드리지 않습니다.
5. **선택 항목 적용** — 실제로 이름이 바뀌고, 분류 폴더가 만들어져 그 안으로 이동합니다.

### 자동 감시

`새 스캔 파일 자동 감시`를 켜두면 30초마다 폴더를 다시 확인해 새 파일을 자동 분석합니다.
`자동 적용`까지 켜면 확인 절차 없이 이름 변경·이동까지 끝냅니다.
익숙해지기 전에는 자동 적용을 끄고 결과를 눈으로 확인하는 편을 권합니다.

### 파일명 규칙

`파일명 규칙` 칸에 자리표시자를 조합합니다. 값이 비어 있으면 앞의 구분자와 함께 사라집니다.

| 자리표시자 | 내용 | 예 |
|---|---|---|
| `{date}` | 문서의 핵심 날짜 | `2024-03-15` |
| `{type}` | 문서 종류 | `세금계산서` |
| `{issuer}` | 발행처 | `국민건강보험공단` |
| `{title}` | 내용 제목 | `2024년 건강검진 결과` |
| `{category}` | 분류 | `의료` |
| `{orig}` | 원래 파일명(확장자 제외) | `SCAN_0021` |

기본값 `{date}_{issuer}_{title}` → `2024-03-15_국민건강보험공단_2024년 건강검진 결과.pdf`

### 분류 폴더

`분류 목록`에 쓰고 싶은 폴더 이름을 미리 적어두면 AI가 **그 중에서만** 고릅니다.
비워두면 AI가 문서를 보고 알아서 분류를 만듭니다.
선택한 폴더에 이미 있는 하위 폴더 이름도 자동으로 후보에 들어가므로,
쓸수록 분류가 흩어지지 않고 같은 이름으로 모입니다.

## 무료 플랜에서 주의할 점

Gemini 무료 플랜은 분당 요청 수(RPM)와 하루 요청 수에 한도가 있습니다.
`분당 요청 수` 설정값에 맞춰 앱이 자동으로 간격을 두고 요청하며,
한도 초과(429) 응답을 받으면 기다렸다가 자동으로 재시도합니다.

- 한도가 자주 걸리면 RPM을 낮추거나 `gemini-2.5-flash-lite` 모델로 바꿔보세요.
- 페이지 수가 많은 문서일수록 토큰을 많이 씁니다(PDF 1페이지당 약 258토큰).
- 최신 한도는 [Gemini API rate limits 문서](https://ai.google.dev/gemini-api/docs/rate-limits)를 확인하세요.

## 알려진 제약

- **파일 크기 15MB 초과 시 건너뜁니다.** 인라인 첨부 요청 한도(20MB) 때문입니다.
  큰 문서는 스캐너 해상도를 낮추거나 분할해서 다시 넣으세요.
- 브라우저 폴더 권한은 탭을 닫으면 해제됩니다. 다시 열면 `폴더 선택`을 한 번 더 눌러야 합니다.
  (권한이 살아있는 동안에는 지난 폴더에 자동으로 다시 연결합니다.)
- 스캔 품질이 나쁘면 판독 정확도가 떨어집니다. `요약` 칸과 이름을 확인한 뒤 적용하세요.
- 이미 처리한 파일은 `이름:크기:수정시각` 기준으로 기억해 건너뜁니다.
  다시 처리하려면 `이미 처리한 파일 건너뛰기`를 끄세요.

## 파일 구조

```
index.html      화면
styles.css      스타일
js/store.js     설정·폴더 핸들·처리 기록 저장 (localStorage + IndexedDB)
js/fs.js        폴더 읽기, 이름 변경, 분류 폴더로 이동
js/gemini.js    Gemini API 호출, RPM 제한, 재시도
js/app.js       화면 제어와 작업 흐름
serve.js        로컬 테스트용 정적 서버 (배포에는 불필요)
```
