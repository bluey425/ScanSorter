ScanSorter

스캔한 PDF를 AI가 읽고, 이름 짓고, 분류 폴더로 정리합니다

이 브라우저는 지원하지 않습니다. 로컬 폴더에 직접 접근하려면 Chrome 또는 Edge 데스크톱 브라우저가 필요합니다. (Firefox·Safari·모바일 브라우저는 File System Access API를 지원하지 않습니다.)

1. 설정

Google AI Studio에서 무료로 발급받으세요. 키는 이 브라우저에만 저장되며, 파일과 함께 Google 서버로만 전송됩니다.

무료 플랜 한도에 맞춰 자동으로 간격을 둡니다.

사용 가능: {date} {type} {issuer} {title} {category} {orig} — 값이 비면 자동으로 생략됩니다.

여기 적힌 분류를 우선 사용합니다. 선택한 폴더의 기존 하위 폴더 이름도 자동으로 후보에 포함됩니다.

2. 스캔 폴더 선택

선택된 폴더 없음

선택한 폴더 안의 PDF·이미지 파일만 읽습니다. 하위 폴더는 건드리지 않습니다.

3. 분석 & 적용

상태 원본 파일명 분류 새 파일명 요약
폴더를 선택하면 파일 목록이 여기에 표시됩니다.

기록


  









  파일은 브라우저에서 Google Gemini API로 직접 전송되며, 별도 서버에 저장되지 않습니다.
